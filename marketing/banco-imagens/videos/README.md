# Vídeos de fundo para os reels

Clips curtos de bancos gratuitos (Pexels, Pixabay) ou gerados por IA (ex.: Google Vids), sem rostos gerados por IA.
- MP4, de preferência vertical (9:16); horizontais servem, são recortados ao centro.
- Curtos: 5 a 20 s e no máximo 20 MB cada (o repositório não é um arquivo de vídeo). Cortar antes de carregar, se for preciso.
- Nome: `tema-descricao-curta.mp4` (ex.: `avaliacoes-mao-telemovel-cafe.mp4`).
- Cada vídeo leva uma linha em `../licencas.md` (origem, autor, licença). Sem linha, não se usa.
- Os reels saem sem som; o som original destes clips não é usado.
